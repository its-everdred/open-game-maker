# Fidelity ladder

Read the ticket's `phase:*` and `model:*` labels and the review ledger before starting. Build only the current rung:

| Phase | Default effort | Deliverable |
| --- | --- | --- |
| mock | low | The cheapest thing the creator can judge: an image or static screen mock, rough sound takes, paper or clip mock. |
| prototype | medium | A refined render in context, edited sound on its event, playable greybox, or clickable screen in the shell. |
| build | xhigh | The asset, mix, mechanic, or real screen integrated in the game. |
| polish | high | Review rounds on the live build. |

Each round, post its media and one Command or review request, then end the turn and wait. Follow the media rules in
the [prototype ladder](../gm-new-game-plan/references/prototype-ladder.md): use close-ups, GIF or MP4 for motion,
and audio for sound. Never skip a rung that the creator has not approved.

Never raise or lower your own effort or ask for more effort. The reconciler changes it after approval. On approval,
continue on the same ticket at the next rung, using the approved round as the reference. Replace throwaway code from
earlier rungs rather than polishing it. Ship each approved rung to production when it improves on live.
