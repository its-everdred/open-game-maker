# Open Game Maker 2000

Kevin's voice-first game maker. This repo holds research, the scope, prototypes and the skills Game Maker's agents will
use. Work here the way those agents will work: dogfood the skills.

- **Creator requests** (a scene, a screen, a look): follow `gm-design-loop`, with `gm-assets` (packs first, lineups),
  `gm-asset-variants` (clone, never edit originals) and `gm-verify` (look before sending; MP4 for the phone).
- **No needless text** in what you build: a button whose icon is clear gets no label (put the words in `aria-label`),
  and no taglines, captions or helper sentences unless Kevin asks for them.
- **Scripted edits to JS** (python/sed splices): never put a `//` comment inside a replacement unless the line ends
  there; use `/* */` mid-line. A swallowed tail is still valid syntax, so `node --check` won't catch it (it dropped a
  scene's arguments and an iframe's attributes here); render or run the change before moving on. A long-running loop (auto-update.sh, command-listener.sh) keeps running the old copy after you `mv` a new one in: kill it by pid and relaunch it, or the change never applies (auto-update ran Nov 11 code for 3 days, 2026-11-14). Never edit a shell script in place while a run of it is in flight (bash reads it as it goes; an og-merge.sh edit broke run 329 after its CI passed, 2026-11-13): write a new file and `mv` it over.
- **Scripted waits** (a chain that polls a log for an earlier step): match a terminal marker the step itself writes (`exit=0 <step>`), Background agents wait the same way: one background command that ends on a terminal marker, one report at the end, no per-minute "still building" turns to the main session (2026-11-25: wasted tokens).
  never line adjacency (`grep -A1`); a stray log line between marker and status stalled the tiers render chain for 90 minutes. Waiting on a process: `pgrep -f` matches the waiting shell's own command line, so wait on a pid (`while kill -0 $PID`) instead (a Sonniss retry waited on itself overnight); the same goes for `pkill -f`, which kills the calling shell (2026-11-09): kill by pid. To find pids by command line, use `executor/procs.sh '<regex>'` (excludes the caller and its ancestors; anchor the regex, e.g. `'^python3 .*mock-broker\.py'`): the self-match recurred three times on 2026-11-19/20 despite this rule.
