# Factory landing page

`index.html` is the root page template. The build versions its logo URL and copies the styles and compiled runtime into the site output. The `variant=b` and `variant=c` query parameters preview the alternate frame treatments; the default retains the approved rounded treatment.

The conveyor and device illustrations use CC0 assets from Kenney's New Platformer, Tiny Dungeon, and Sketch Town collections, and KayKit's Adventurers, Skeletons, Medieval Hexagon, Dungeon, and Fantasy Weapons collections. The KayKit character and tower thumbnails were locally keyed and resized. The editor still depicts Goblin Cellar, which uses Kenney assets. Geist and Geist Mono are distributed under the included SIL Open Font License.

The editor clip and review-scene images are explicitly marked as pending until their real media is available. Do not replace them with simulated footage.
