# Docs visual mock

This is a review-only HTML mock for issue #1361, based on the yellow B2 marketing direction. Serve `apps/site/mock` over HTTP and open `/docs/` to switch between Human and Agent views. The audience choice is remembered locally.

The navigation and cards illustrate planned pages; their fragment links are placeholders. The documentation content, generated references, and mobile navigation are for the next rung and are not implemented here. This directory is not included in the production site build.

The screenshots show each audience at 390 × 844 and 1440 × 900. They were captured in Chromium with software rendering.
