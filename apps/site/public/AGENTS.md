# Open Game Maker 2000

Open Game Maker 2000 is an invite-only game maker where people bring art and
guide the creative decisions while agents build and revise games. The process
goes from an idea through mocks, prototypes, playable review, build and
publication, with creator review throughout.

The [homepage](/) describes the factory, editor, review process and supported
devices. The [setup guide](/setup) explains how to run an instance yourself.
Access to the hosted app is by invitation.
